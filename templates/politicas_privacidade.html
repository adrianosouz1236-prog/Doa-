1. Quem somos

Doa+ Plataforma de Doações

Email: contato@doamais.org

Telefone: (11) 99999-9999

A Doa+ é uma plataforma que conecta doadores a ONGs, facilitando doações de itens e financeiras de forma segura e transparente.

2. Informações que coletamos

2.1. Informações fornecidas por você

  • Dados cadastrais: Nome, email, telefone, CPF (opcional), endereço
  • Dados de doação: Histórico de doações, valores, mensagens
  • Dados bancários: Conta bancária para saques (apenas para ONGs)
  • Dados de perfil: Foto, descrição, localização (apenas para ONGs)

2.2. Informações coletadas automaticamente

  • Dados de navegação: IP, tipo de navegador, páginas acessadas
  • Cookies: Preferências e sessão
  • Dados de interação: Cliques, tempo de permanência

2.3. Informações de pagamento

  • Não armazenamos dados de cartão de crédito ou informações bancárias completas
  • Os dados de pagamento são processados exclusivamente pelo PagSeguro, nosso parceiro de pagamentos
  • Armazenamos apenas o ID da transação e o status do pagamento

3. Como usamos suas informações

  • Para operar a plataforma: Processar doações, conectar doadores e ONGs
  • Para comunicação: Enviar confirmações de doações, notificações de novas necessidades
  • Para melhorar nossos serviços: Analisar uso da plataforma, identificar tendências
  • Para cumprir obrigações legais: Atender à LGPD, evitar fraudes
  • Para processar pagamentos: Enviar dados para o PagSeguro apenas para finalizar transações

4. Compartilhamento de informações

4.1. Com quem compartilhamos

  • PagSeguro: Para processar pagamentos. O PagSeguro tem sua própria política de privacidade.
  • ONGs: Quando você faz uma doação, seu nome e mensagem são compartilhados com a ONG.
  • Parceiros: Apenas com seu consentimento explícito.
  • Autoridades legais: Quando exigido por lei.

4.2. O que NÃO compartilhamos

  • Não vendemos seus dados para terceiros
  • Não compartilhamos dados bancários com outras ONGs ou usuários
  • Não compartilhamos dados de pagamento com ninguém além do PagSeguro

5. Armazenamento e segurança

5.1. Medidas de segurança

  • ✅ Criptografia de dados sensíveis (senhas, contas bancárias)
  • ✅ HTTPS em todas as páginas
  • ✅ Autenticação de dois fatores (2FA) opcional
  • ✅ CSRF Protection em todos os formulários
  • ✅ Rate limiting para prevenir ataques de força bruta
  • ✅ Logs de segurança para auditoria

5.2. Retenção de dados

  • Mantemos seus dados enquanto sua conta estiver ativa
  • Após exclusão da conta, seus dados são removidos em até 30 dias
  • Dados de transações financeiras são mantidos por 5 anos (exigência legal)

6. Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018), você tem direito a:

  • Confirmação e acesso: Saber se tratamos seus dados e acessá-los
  • Correção: Corrigir dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação: Solicitar a remoção de dados desnecessários
  • Portabilidade: Receber seus dados em formato estruturado
  • Informação sobre compartilhamento: Saber com quem compartilhamos seus dados
  • Revogar consentimento: A qualquer momento
  • Oposição: Opor-se ao tratamento de seus dados

Para exercer seus direitos, entre em contato pelo email: contato@doamais.org

7. Cookies e rastreamento

Utilizamos cookies para melhorar sua experiência:

  • Cookies essenciais: Para autenticação e funcionamento da plataforma
  • Cookies de preferências: Para lembrar suas configurações
  • Cookies de análise: Para entender como você usa a plataforma

Você pode gerenciar seus cookies nas configurações do seu navegador.

8. Alterações nesta política

Podemos atualizar esta política periodicamente. Notificaremos você sobre mudanças significativas através de:

  • Email para usuários cadastrados
  • Banner no site
  • Atualização da data no topo da página

Recomendamos revisar esta política regularmente.
